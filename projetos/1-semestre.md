# Primeiro Semestre (2025-1)

O projeto do primeiro semestre teve como empresa parceira a própria Fatec. Os requisitos foram apresentados pelo professor Egydio, que assumiu o papel de cliente final.

O problema apresentado consistia na necessidade de um sistema web para registrar e gerenciar os atestados médicos de alunos, evitando perda de dados e tornando o processo mais ágil, além de avaliar equipes ágeis nos papéis do Scrum (Scrum Master, Product Owner e Time de Desenvolvimento) por meio do método PACER (Produtividade, Autonomia, Colaboração e Entrega de Resultados).

Como solução, minha equipe desenvolveu o SIRAAS (Sistema de Registro de Atestados e Avaliação Scrum), um sistema web com cadastro, consulta e gestão de atestados, páginas para docentes, estatísticas de afastamento e cadastro dos membros Scrum.

[GIT](https://github.com/Gabrielle0905/SIRAAS)

## Tecnologias Utilizadas

As seguintes tecnologias foram utilizadas nesse projeto:

* HTML5 e CSS3 - Estruturação e estilização das páginas do sistema;
* JavaScript - Interações das páginas no front-end;
* Python - Linguagem utilizada no back-end;
* Flask - Framework web utilizado para receber os dados dos formulários de cadastro;
* Figma e Canva - Prototipação e design das telas;
* Adobe Photoshop - Edição de imagens;
* Astah - Modelagem dos casos de uso;
* Visual Studio Code - Ambiente de desenvolvimento.

## Contribuições Pessoais

Nesse projeto atuei como desenvolvedora. Desenvolvi o HTML e o CSS da página do docente e criei o HTML e o CSS da página de estatísticas de afastamento. Estruturei o HTML da página de cadastro dos membros Scrum e implementei o back-end desse cadastro com Flask, recebendo os dados dos formulários e armazenando-os em arquivos .txt. Também modelei os casos de uso no Astah, colaborando com a documentação e o entendimento funcional do sistema.

## Soft Skills

**Adaptabilidade e aprendizado contínuo:** Por se tratar da minha primeira experiência com programação, precisei me adaptar a um ambiente completamente novo, sem conhecimentos prévios na área. Ao longo do projeto, enfrentei desafios relacionados ao aprendizado das tecnologias e à compreensão do processo de desenvolvimento, buscando constantemente novos conhecimentos para contribuir com a equipe.

**Comunicação e proatividade:** Durante o andamento do projeto, percebi que a sprint havia começado sem que o Product Owner tivesse finalizado o backlog. Embora a equipe ainda não tivesse identificado o impacto dessa situação no cronograma, comuniquei o problema aos demais integrantes, permitindo que nos organizássemos para resolver a pendência e evitar maiores atrasos no desenvolvimento.
